# DOON Voice 0.5.17 修正・検証記録

確認日: 2026-09-15。対象: 単体リポジトリの0.5.16（`078012f`）を基準にしたローカル修正版。

主担当: 石川（原文・常駐・統合）。協働: 長谷川（CLI・Rust独立レビュー）、村上（画面）、西田（TypeScript独立レビュー）。

## 修正した問題

| 指摘 | 修正と再発確認 |
|---|---|
| DV-001 原文の文頭・タグ以前が消える | 認識原文からのフィラー削除を廃止。思考タグ除去をAI出力専用に分離。「あーちゃん」「あーだこうだ」、フィラー、文字列の `</think>` をAIなし・原文回収まで保持 |
| DV-002 処理中のAI表示と実際の送信先が食い違う | マイク準備・録音・処理中の選択を両画面で無効化。保存キューの実行時にも再確認し、Rust側でも設定変更を拒否。同一設定の同期と保存済み設定の遅い応答を許容 |
| DV-003 CLI終了後も応答期限まで待つ | 標準出力の終了を明示通知し、入力スレッドが通知経路を保持していても失敗を返す。最後のJSONより後に終了通知を並べ、エラー詳細待ちは100msに制限 |
| DV-004 Windowsで閉じた画面を再表示できない | macOS／Windows共通の常駐アイコンに「開く」「終了」を追加。通常の終了要求では処理中・未回収の文章を保護 |
| 追加: 小さい画面の取消ボタンが横にはみ出す | 幅390pxの準備中・処理中をテスト化し、ボタンを元の列内に配置 |
| 追加: 初期ショートカットの不一致 | Rustの初期値と現行仕様を画面の `Ctrl+Alt+Space` に統一。保存済み設定は維持 |

修正前の失敗を先に確認し、テストのチェックポイントを保存した。CLIはエラーのみ・無出力・遅いエラー出力・終了直前の最終JSON・無応答期限・取消を模擬子プロセスで確認した。

- ZIP: `dist/DOON Voice-macOS.zip`

## 未検証・公開前の残余

実マイク、他アプリへの実貼り付け、外部AIへの文章送信、Windows／Intel Mac実機での操作は今回実施していない。Windowsの再表示導線はコードを修正した段階であり、Windows実機での成功とは扱わない。

処理中の入力先アプリ切替を固定する機能はない。処理中は入力先を切り替えない。強制終了時はメモリ内の文章を保持できない。

Windows音声エンジンのVCOMP140依存、既存MSVC DLLの由来・再配布条件、sigchldの上流LICENSE表示不足は前版からの確認事項として残る。詳細は [OSS表示](OSS-NOTICES.md)。ライセンス資料の照合を再配布許諾の確認済み表示とはしない。

GitHubへのpush・タグ作成・公開Release更新は実施していない。
