FIRST SETUP GUIDE

DOON Voice
インストール手順

話した内容を文字にして、いまカーソルがある入力欄へ入れるアプリです。最初は「AIなし」で動作を確かめてください。

はじめる前に

配布フォルダから、ご利用のOSに合うZIPをダウンロードします。ZIPの中身をすべて展開してから、MacはDMG、WindowsはMSIを開いてください。

この手順書の内容
  1. Mac・Windowsへ入れる
  2. 最初の設定
  3. 音声入力を使う
  4. うまくいかないとき

1. Mac・Windowsへ入れる

Mac

  1. DOON Voice-macOS.zip をダブルクリックして展開します。
  2. 中の .dmg ファイルを開きます。
  3. 表示された DOON Voice を Applications フォルダへドラッグします。
  4. ApplicationsフォルダからDOON Voiceを開きます。
開けない場合macOSの表示した案内を確認してください。警告や組織の端末制限で止まる場合は、表示された文言を添えて配布元へ連絡してください。

Windows 10 / 11（64ビット）

  1. DOON Voice-Windows.zip を右クリックし、すべて展開を選びます。
  2. 展開したフォルダ内の DOON Voice_0.5.20_x64_en-US.msi をダブルクリックします。
  3. 画面の案内に沿ってインストールします。
  4. スタートメニューからDOON Voiceを開きます。
警告や制限が出た場合テスト版はコード署名証明書を付けていません。組織のPCで起動が止まるときは、表示された文言を添えて管理者または配布元へ連絡してください。

2. 最初の設定

  1. DOON Voice左下の 接続と設定 を開きます。
  2. 音声認識 の モデルを取得 を押します。約574MBあるため、初回はインターネット接続が必要です。
  3. マイクの利用を許可します。Windowsでは「設定」で マイク を検索し、マイクとデスクトップアプリのアクセスをオンにします。
  4. Macでは カーソル位置へ入力 の 許可する を押し、システム設定のアクセシビリティでDOON Voiceをオンにします。
  5. 最初は 文章の仕上げ で AIなし を選びます。
AIは後からで大丈夫ですAIなしでも、話した内容をこのPC内で文字にできます。ChatGPT、Claude、Geminiを使う場合だけ、各サービスのCLIとログインが必要です。

3. 音声入力を使う

01入力したい場所をクリック
02Ctrl + Alt + Space で開始
03もう一度同じキーで停止
04文章が入力欄とクリップボードへ入る

開始・停止キーは 接続と設定 で変更できます。画面を閉じたあとも、Macはメニューバー、Windowsは通知領域のDOON Voiceアイコンからもう一度開けます。

入力されなかったときホーム画面の 原文をコピー または 文章をコピー で文章を回収できます。コピーした内容は、入力したいアプリへ手動で貼り付けてください。

4. うまくいかないとき

話しても録音が始まらないマイクの許可と、音声認識モデルの取得状態を確認してください。開始・停止キーが他のアプリと重なる場合は、接続と設定で変更します。
文字は出るが入力欄へ入らないMacはアクセシビリティでDOON Voiceがオンか確認します。Windowsは入力先アプリをクリックしてカーソルを置いてから試します。原文をコピーして貼り付ける方法も使えます。
アプリが開かない警告やエラーの文言を控えて、配布元へ知らせてください。ZIP内のファイルを直接開かず、展開したフォルダから開いているかも確認します。
AIの設定ができないAIなしなら設定不要です。ChatGPT、Claude、Geminiを使う場合は、それぞれのCLIをPCへ入れてログインします。

テスト時に知らせてほしいこと

  • 認識された文章
  • 開始から入力までにかかった時間
  • 入力先に使ったアプリ
  • エラーや警告が出た場合は、その画面の文言と操作手順
DOON Voice テスト配布版向けの手順書です。音声認識は端末内で行い、AIなしでは本文を外部AIへ送信しません。
