| 文字起こし | RCS-002 挨拶・正常な反復を捨てる | 語句だけを根拠にした破棄を廃止。有音／無音の既存試験も維持 |

| 処理制御 | RCS-005 Whisperの期限・終了状態不足 | 300秒期限、終了コード、出力量、中止、停止要求失敗を処理。部分本文は手動回収 |

| 上限 | RCS-014 WAVヘッダー44byteの境界 | 録音上限とAPI上限を統一。上限PCM＋WAVヘッダーの試験 |
| 梱包 | RCS-015 旧版インストーラー混入 | 現版・対象機種に合う1個だけを選び、ゼロ／複数候補を拒否 |

## 追加した保護

- AIなしモード。本文と辞書を文章整形AIへ送らない。
- 設定保存を直列化し、保存成功後だけ画面へ確定。初期同期前・保存失敗時はOSショートカットも開始しない。
- コピー・再試行・破棄・取消の世代番号を照合。録音中の結果操作を停止。
- 部分認識の警告を再試行後も保持し、自動貼り付けを禁止。エンジン停止に失敗した場合は、取得済み本文を残して再録音を止める。
- Claude/Geminiの会話を発話ごとに分離。Codexは発話ごとの一時スレッドを使用。
- 音声判定でPCM全量のfloat配列を複製せず、フレームごとの集計に変更。
- 公開前に両OSのUI検証、Windowsエンジン起動、インストーラー内の表示検査を必須化。
- 初回DMGの署名整合性検査が失敗したため、証明書不要のad-hoc署名を明示。再生成したDMGでdeep/strict検証を通した。Developer ID署名・Apple公証とは別。
