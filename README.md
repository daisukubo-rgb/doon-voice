# DOON Voice

話した内容をPCの中で文字にして、カーソルがある入力欄へそのまま入れるデスクトップアプリです。

このリポジトリには、完成版のインストーラーと、アプリの「更新を確認」が使うファイルだけを置いています。

## ダウンロード

[Releases](https://github.com/daisukubo-rgb/doon-voice/releases/latest) から、お使いのPCに合うZIPを1つだけダウンロードしてください。

| お使いのPC | ダウンロードするファイル |
| --- | --- |
| Mac（Apple Silicon：M1以降のチップ） | DOON Voice-macOS.zip |
| Mac（Intel） | DOON Voice-macOS-Intel.zip |
| Windows 10／11（64ビット） | DOON Voice-Windows.zip |

ZIPを展開し、中のDMG（Mac）またはMSI（Windows）を開いてインストールします。初めて開く時の手順は https://doon-inc.com/doon-voice/#first-open にあります。
